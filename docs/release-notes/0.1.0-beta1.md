# Kaggle-Kit v0.1.0-beta1 — release candidate (not published)

**Status:** proposed beta candidate on an unmerged pull request. This file is

- **Intended version:** `0.1.0-beta1`
- **Source commit:** `{{SOURCE_SHA}}`
- **Compatibility:** no browser storage, conversation, profile, credentials,

  and fail-closed behavior remain in force.

## Changes in this candidate

- Correct the `Resolve nightly metadata` version assignment in both jobs of
  `.github/workflows/nightly-release.yml`. The old escaped quotes caused Bash
  to fail parsing `$(...)`, before any validation or build work ran. A
  regression test executes the exact version-assignment line from both jobs.
- Add calculator conversion regression coverage for the previously reported
  `100 °F → °C` and `100 km/h → mph` results, both with an explicit relative
  tolerance of `1e-6`, plus reverse conversions, supported unit categories,
  signs, decimals, zero, case/whitespace normalization, unsupported units,
  incompatible categories, and non-finite values. Direct execution on the
  audited implementation returned approximately `37.7777778 °C` and
  `62.1371192 mph`; the historical bad values did not reproduce, so converter
  arithmetic was not changed. A tool-loop regression also pins the
  `calculator_convert(value, from, to)` argument mapping.
- Update the lockfile's transitive `fast-uri` dependency from 3.1.8 to 3.1.9,
  within the existing `ajv` dependency range, to resolve the npm audit
  advisories without adding or changing a declared runtime dependency.
- Prepare package, lockfile and app version metadata consistently for
  `0.1.0-beta1`. The existing release workflow regex accepts
  `v0.1.0-beta1`; the artifact validator imposes no conflicting tag-suffix
  restriction. No release policy was relaxed.

## Verification boundaries

The offline system-prompt evaluation validates its 17 cases, 36 automated
checks and 45 manual criteria only. No model inference was run, so this
candidate makes no claim that system-prompt quality or native tool-calling
behavior improved on any real model. Mock and deterministic tests establish
only their tested integration and policy behavior.

Kaggle GPU/TPU deployments, live model tool calling, hosted providers, public
tunnels, and external MCP/HTTP services remain unverified as documented in the
deployment matrix. The Nightly Release fix has local shell/regression-test
evidence; the scheduled workflow has not yet had a successful post-fix live
run. A release dry-run is local artifact validation, not publication.
