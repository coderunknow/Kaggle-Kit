## Fixed in this candidate

- **Nightly Release always failed at `Resolve nightly metadata`**
  (confirmed; GitHub run 40029657246 and its predecessors). The step read
  the package version with backslash-escaped quotes,
  `node -p \"require('./package.json').version\"`, inside a command
  substitution. GitHub passes the literal `run:` block to bash, which
  rejects that shape with `syntax error near unexpected token '('` before
  any later step runs — so no nightly prerelease could ever be produced.
  Both occurrences (verify and publish jobs) now use the unescaped shape
  already proven in `release.yml`. Regression test:
  `test_nightly_version_line_executes` executes the exact lines from the
  workflow; it fails on the old text and passes on the fix, and the whole
  extracted metadata step was executed successfully in a local simulation.
- **Transitive dependency advisories:** `npm audit` reported one moderate
  package (`fast-uri` 3.1.8 via `ajv`, four GHSA entries fixed in 3.1.9).
  Lockfile-only update to 3.1.9 (inside the existing `^3.0.1` range; no
  `package.json` dependency change). `npm audit` now reports 0
  vulnerabilities.
- **Calculator/conversion regression leads closed with tests:** an earlier
  report claimed `100 °F → °C ≈ 1036.566…` and `100 km/h → mph ≈ 345.52…`.
  Re-verified against the current implementation on 2026-10-24: both
  conversions are correct (`37.7777778 °C`, `62.1371192 mph`). No code
  change was needed; explicit regression assertions with a stated 1e-6
  relative tolerance, plus reverse/negative/zero/case-whitespace and
  unknown/incompatible/non-finite cases, now lock the behaviour in.

## Not live-verified (unchanged from dev7)

- No live model of any kind ran here: native tool calling, streaming and
  benchmark evidence is deterministic mock protocol evidence with
  synthetic tool results, never real-model behaviour.
- Raon on T4 x2, Spark-X2.6-4B on T4 x2 and Qwen on TPU v5e-8 remain
  implemented but not live-verified; Raon/Spark on TPU remain blocked with
  evidence. The Qwen T4 x2 deployment is pre-existing and not re-run live.
- Keyless web search and browser Python remain deferred by evidence;
  `web_open` is page retrieval, not search; Brave stays optional.
- Playwright browser end-to-end and the Docker sandbox integration cannot
  run in the development sandbox (no Chromium binary, no Docker CLI);
  the CI jobs on the pull-request head are the verification path and this
  candidate is not acceptance-complete until they pass there.
