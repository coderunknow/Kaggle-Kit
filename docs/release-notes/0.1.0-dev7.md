# Kaggle-Kit v0.1.0-dev7 — partial candidate

**Status:** unpublished development candidate; not acceptance-complete.
No tag or release is created by this work. Keyless public-web search is still
missing; browser Python is deferred pending proven isolation and integration.

- **Intended version:** `0.1.0-dev7`
- **Source commit:** `{{SOURCE_SHA}}`
- **Compatibility:** existing profiles, conversations, credential modes,
  retention defaults and advanced integrations keep their stored formats.

## Implemented

- Ordered first-run connection guidance and endpoint-type help, preserving the
  effective normalized URL, optional model authentication and actual inference
  verification. Empty discovery now explains manual model entry.
- Basic/Advanced views without resetting unsaved or existing advanced values.
  A connected active profile offers Start chatting.
- Explicit reviewed keyless built-in grant (Save required): calculator,
  conversion, uploaded files, model-endpoint diagnostics and public-page
  retrieval. Presets only narrow the current allowlist; they never grant new
  permissions. Native tool verification remains mandatory for tool chat.
- Fixed a stale green editor test after changing the typed model credential.
- Bound public-page/Brave operations to 12 seconds total, including DNS and
  redirects, retaining public URL validation and DNS-pinned requests.
- Validate the Brave results array rather than treating malformed payloads as
  empty results or throwing an incidental TypeError.
- Refuse an already-cancelled Python request before spawning Docker.
- Browser regression coverage for Basic/Advanced state preservation at 360px
  and the reviewed-grant → probe → calculator → model-continuation path.

## Incomplete and unverified

**No keyless search implementation ships.** Public page opening is not search.
The sandbox cannot access candidate public search hosts; no particular public
source's policy and usable responses were verified. Optional Brave remains in
Advanced and needs a separate provider key. No scraper, invented result or
external search-link placeholder was substituted.

**No browser Python implementation ships.** Pyodide worker documentation and
actual distribution sizes were investigated. A same-origin worker is not a
complete isolation boundary for Python's JavaScript interop, and the existing
server tool lifecycle has no browser-result bridge. Docker stays explicitly
optional, digest-pinned, bounded, network-disabled and approval-gated. No host
or third-party execution fallback was introduced.

No live model, public search/Brave provider, Kaggle GPU/tunnel, local Docker or
Windows runtime was available for this work. Chromium E2E uses the actual built
app with a deterministic local mock model, not a live model. Full evidence,
policy sources and follow-up requirements are in [the audit](../dev7-audit.md)
and [verification metadata](../release/environment.json).

Keep the PR open/draft until the outstanding search requirement is resolved.
Passing local checks and a release dry run do not make this acceptance-complete
or guarantee absence of bugs. Release publication is out of scope.
